# AGENTIC R&D & IMPLEMENTATION BLUEPRINT
## Dual-Course Synthesis (Nov 2025 → June 2026)  
### Unified Harness Declaration
All delegation loops default to the **Hermes CLI + Antigravity unified harness** (`antigravity agent invoke --harness hermes` or Google AI Studio Build mode). Skills follow the agentskills.io progressive-disclosure specification (L1 metadata always loaded, L2 body on trigger match, L3 references/assets/scripts on demand). Model routing is strictly dynamic:

- **Premium Frontier** — deep multi-step reasoning, architecture, threat modeling, ADRs, research synthesis  
- **Strong Coding** — scaffolding, declarative configs, schemas, Meta-Prompt execution, evaluation harnesses  
- **Fast Flash** — high-throughput validation, syntax checks, mechanical commits, scheduled tasks  

No frozen model versions. No raw application code is generated by this blueprint; only Meta-Prompts, declarative specifications, Gherkin BDD, and decision matrices are produced.

Static Reference Anchors  
- WP-F1…F5 (Nov 2025) + WP-S1…S5 (June 2026). Course-2 logic always supersedes Course-1 on overlap.
